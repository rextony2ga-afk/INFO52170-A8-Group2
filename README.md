## Application Overview

The team is developing a simple web application that demonstrates the complete DevOps workflow required for Assessment 8.

Planned features include:

* Homepage with a welcome message
* About page
* Navigation between pages
* Automated CI/CD checks
* Automated testing
* Docker containerization
* AWS EC2 deployment
* Secure AWS Security Group configuration
* Team information footer
